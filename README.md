
# 🎤 Agentic AI Debate Coach & Presentation Analysis Platform

A full-stack, role-based AI-powered platform designed to help learners improve their **debating, public speaking, argumentation, critical thinking, communication, and presentation skills**.

The platform combines AI-powered debate evaluation, speech-to-text transcription, argument analysis, logical fallacy detection, counterargument generation, rebuttal generation, speech improvement, presentation analysis, performance tracking, coaching, educator monitoring, and administrator management into a single platform.

## 📌 Project Overview

Traditional debate and presentation practice often depends on teachers, coaches, or peers to provide feedback.

The **Agentic AI Debate Coach** provides an interactive environment where learners can practice debates, analyze their arguments, receive AI-generated feedback, identify weaknesses, and continuously improve their communication skills.

The platform supports four major roles:

- 🎓 Learner
- 🧑‍🏫 Debate Coach
- 👩‍🏫 Educator
- ⚙️ Administrator

# 🤖 AI Features

## 🧠 AI Debate Evaluation

After a learner completes a debate, the AI evaluates the response using multiple performance dimensions.

### Evaluation Metrics

| Metric | Description |
|---|---|
| Grammar | Evaluates grammar and language correctness |
| Logic | Evaluates reasoning and argument structure |
| Confidence | Evaluates confidence and communication |
| Relevance | Evaluates how closely the response addresses the topic |

The system generates:

- Individual scores
- Overall score
- Percentage
- Grade
- AI summary
- Strengths
- Weaknesses
- Coach recommendations

---

## ⚠️ Logical Fallacy Detector

The platform analyzes arguments and identifies possible logical fallacies.

For each detected fallacy, the system provides:

- Fallacy name
- Description
- Explanation
- How to fix the argument

Example:

**Fallacy:** False Dilemma

**Description:**  
The argument presents only two possible choices when other alternatives may exist.

**How to Fix:**  
Consider additional possibilities before reaching a conclusion.

If no fallacies are detected:

> No logical fallacies detected 🎉

# 🚀 Installation & Setup

## 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd Agentic-AI-Debate-Coach
```

---

## 2. Backend Setup

Navigate to the backend:

```bash
cd backend
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create your `.env` file with the required configuration.

Start the backend:

```bash
uvicorn app.main:app --reload
```

Backend:

```text
http://127.0.0.1:8000
```

Swagger:

```text
http://127.0.0.1:8000/docs
```

---

## 3. Frontend Setup

Open another terminal.

Navigate to the frontend:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Frontend:

```text
http://localhost:5173
```
