# Agentic AI Debate Coach & Presentation Analysis Platform

## Project Overview

The Agentic AI Debate Coach & Presentation Analysis Platform is an AI-powered web application designed to help learners improve their debate, public speaking, and critical thinking skills.

The platform provides role-based dashboards, debate session management, AI-powered argument analysis, logical fallacy detection, counterargument generation, presentation analysis, and personalized recommendations.

This project is being developed as part of the Infosys Springboard Internship.
