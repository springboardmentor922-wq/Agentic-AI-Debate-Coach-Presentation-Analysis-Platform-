# Agentic AI Debate Coach & Presentation Analysis Platform

An AI-powered debate coaching and presentation analysis platform designed to help learners improve communication, confidence, fluency, argumentation, and debate performance.

## Features

- Learner dashboard and practice studio
- AI debate opponent and coaching
- Debate response evaluation
- Argument analysis and performance scoring
- Coach portal with learner feedback
- Educator and administrator dashboards
- Debate history and performance tracking
- Feedback and notification modules
- Speech-to-text using the browser Web Speech API
- PDF and Excel report generation
- Responsive user interface
- Role-based access control
- Client-side data persistence using localStorage

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Web Speech API
- Chart.js
- jsPDF
- SheetJS
- localStorage

## Architecture

The application is implemented as a Vanilla JavaScript single-page application. Client-side data persistence is handled using localStorage. No React, FastAPI, PostgreSQL, MongoDB, JWT, OAuth2, or external LLM API is required by the current implementation.
